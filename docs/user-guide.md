# Smart Shopping: User Guide

A private shopping list for your phone. The app itself is in German; this guide is in English.

## Install

Open the app in your phone's browser and choose "Add to Home Screen" (or "Install"). After the first load it works fully offline. Your data lives only in this browser on this phone. There is no backup, so don't clear the site data.

## The list

The home screen shows your one shopping list for the active shop, in three parts:

1. **Open items**, grouped by aisle in the order of the current shop, alphabetical within each aisle.
2. **Nicht in diesem Laden**: open items from aisles this shop doesn't have. They're dimmed but still work normally.
3. **Erledigt**: checked items, dimmed and collapsed. Tap the heading to unfold it.

## Adding items

1. Tap the **+** button.
2. Search the catalog (the search field filters as you type), pick an item and enter an amount. Use a decimal comma (e.g. `0,5`), or the **+ / −** buttons, which step by a unit-specific size.
3. A short message confirms the add. The sheet stays open, so you can add the next item right away.

Special cases:

- **Already on the list (open):** the app asks whether to add to the existing amount. Yes adds the amounts together. No cancels.
- **Already on the list (checked):** it is reopened with the new amount.
- **Not in the catalog:** create a new item in the add sheet (name, unit, aisle).

## In the store

- **Check off** an item with its checkbox. It moves to *Erledigt*. Tap again to reopen it.
- **Change the amount** by tapping the amount on a row.
- **Remove** an item with its remove button. An undo message appears briefly, with no confirmation dialog.
- **Erledigte entfernen** (in the *Erledigt* section) clears all checked items. It asks for confirmation first. Open items can't be bulk-removed.
- When everything is checked, you see "Alles erledigt!".

## Shops

Tap the shop name at the top to switch shops. This only changes the order and grouping of the list. It doesn't change the content. The app remembers your last shop.

Open the header **Menü** and choose **Läden** to manage shops:

- Create, rename or delete shops. The last remaining shop can't be deleted.
- For each shop, choose which aisles it includes and **drag the handles** to set their order, ideally matching your walk through the store.
- New aisles aren't in any shop until you add them here.

## Catalog

**Menü → Katalog** has three tabs: items, units and aisles. Add, rename or edit entries. Names must be unique ("Name existiert schon."). Items on the list, and units or aisles still used by catalog items, can't be deleted. A message tells you how many are using them. Deleting an aisle only removes it from the shops' lists.

## Sharing the list

**Menü → Liste teilen** creates a link with all open items (checked items are left out) and opens the share sheet; if that isn't available, the link is copied. Whoever opens the link (Android) sees a preview and taps **Importieren**; nothing changes before that.

- If some items are already open on their list, they choose between **Mengen addieren** and **Meine Mengen behalten**. Checked items are reopened with the incoming amount.
- Items are matched by name. For an item that isn't in their catalog, or whose unit differs from the catalog's, the app asks once per item: **Anlegen / Übernehmen**, **Überspringen** or **Abbrechen**.
- A damaged link shows "Link ungültig." and changes nothing.

## Tips

- Set up each shop's aisle order once, and the list then follows your route through the store.
- A shop you rarely visit can skip aisles. Those items stay visible under *Nicht in diesem Laden*, so nothing gets forgotten.
